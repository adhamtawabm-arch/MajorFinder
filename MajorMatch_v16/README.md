# MajorMatch v13

MajorMatch is a client-side major discovery app.

## New in v13
- Career Explorer with search/filter and career-to-major navigation.
- Career salary/outlook reference cards using U.S. occupational benchmarks; local outcomes vary.
- "What you may study" previews on every major detail page.
- Smarter alternative-major recommendations using subject overlap, interest tags, category, and explicit related majors.
- Country-specific university study information: country filter, language, tuition guidance, and application notes.
- Existing university finder, official-site links, map links, saved majors, comparison, fast matching, and responsive 3D UI remain intact.

## Data note
University availability is based on the app's local university directory and broad field coverage. Students should verify the exact degree, intake, tuition, language, accreditation, and admission requirements on the university's official website.

Career pay/outlook references are primarily based on U.S. Bureau of Labor Statistics occupational data and are not guarantees. Local labor markets can differ significantly.
